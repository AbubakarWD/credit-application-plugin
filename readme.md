# Credit Application Plugin
A custom plugin that provides the credit application form for WordPress.

## Features
- Custom credit application form
- WordPress plugin architecture
- Easy deployment and updates
- Can be embedded on pages via shortcode or plugin output

# Usage
1. Download or clone the plugin into your WordPress installation.
2. Upload the plugin folder to:
    wp-content/plugins/
3. Activate the plugin from:
    WordPress Dashboard → Plugins
4. Create or edit any page where you want to display the credit application form.
5. Insert the shortcode:
    [finance_form]
6. Update or publish the page.

The credit application form will automatically render on the front end.
